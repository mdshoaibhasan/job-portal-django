# Job Portal

A Django-based job portal web application.

## Features
- User registration and login
- Job browsing and searching
- Job application system
- Recruiter can post job listings
- Admin can manage users and jobs

## Tech Stack
- Python
- Django
- SQLite (or your database)
- HTML, CSS, Bootstrap

## Project Purpose
This project helps job seekers find jobs and allows recruiters to post job opportunities easily.
